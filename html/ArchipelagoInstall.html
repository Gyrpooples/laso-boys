Archipelago Software Setup Guide

Required Software

Navigate to the Archipelago GIT Page and scroll all the way to the bottom of the page. You should see something like this:

All of you should be on Windows so select the Setup.Archipelago.X.X.X.exe (X.X.X is latest version).

Once the setup downloads run it. Allow it to run and accept the agreement. Click through the menu leaving all options as default until you get to install.

Done! Congrats the first part is complete and you are ready to go to the setup guide for your specific Game .
